# Mobile Stage 4 — campus finance, learner accounts and expenses

The fee register, accountant learner profiles and cashbook entries now use labelled mobile records while preserving wider-screen tables. Every fee amount, admission ID, campus (when applicable), enrolment status and existing action remains available. Removed position-based column hiding, which could hide different financial fields depending on the campus column. Long expense descriptions remain readable; expense amount fields request a decimal keyboard.

Populated fixture review exposed a campus display bug: the finance register received boolean true as its campus filter rather than junior/senior and therefore displayed no rows. It now receives the assigned campus string. The same display scope is applied before creating summary rows, so mixed-campus input cannot create a summary/register mismatch. Existing individual fee calculations, transaction RPC arguments, pending-request protection and backend permissions are unchanged. The accountant learner empty state no longer incorrectly says Junior on Senior accounts.

Passed locally: 12 populated fee register scenarios (admin/accountant/principal at 320/390/768/1280px), visible total/paid/balance/status/enrolment fields, unchanged individual amounts, correct campus row counts and aggregate totals, payment-dialog opening and principal restrictions; mobile accountant expenses/profile checks; 24 learner-profile views and 15 desktop role views; pending-payment dismissal/single-request regression; targeted new/changed component lint and production build. Existing FeesDashboard unused-symbol/effect-style lint findings remain, and its existing getDynamicFee dependency warning is not claimed resolved by this presentation phase. Representative accountant finance screenshots were reviewed.

All writes exercised by browser suites use local synthetic fixtures. No live payments, expenses, fees, orders or Supabase policies were changed. Physical-device and authenticated hosted sign-off remains in Stage 9. Stage 5 continues with teacher daily work.
