# Learning library and newsletters: daily guide

## Teachers

1. Sign into your own staff account. Complete any required first-login password change directly in the portal.
2. Senior: choose your assigned subject and form, then **Learning library**. Junior/ECD: choose your assigned class, open **Learning library**, then select the curriculum subject.
3. Enter the title, description, academic year and term. Upload a PDF, Word, PowerPoint, JPG, PNG or WebP file, up to 10 MB. PDFs are usually easiest to read on phones. Avoid scans/photos so large that families struggle to download them.
4. Save the draft and inspect the saved attachment. **Publish** makes it available to verified parents whose active learner matches the campus, grade/form and stream. A blank stream covers all streams within that exact class. These are class resources, not individual elective enrollment lists.
5. Replace a file by uploading the new version. The existing file remains active until the replacement is checked and finalized. Archive notes to withdraw them; do not delete history to correct a mistake.

After a connection error, reopen/refresh the resource to see what saved before retrying. Do not make a second copy simply because a response was slow. If an allocation changes, old editing rights end; ask Admin to correct the allocation. Published scope/history is not moved to another class or campus. After a learner is promoted, the initial library follows the learner's current class; it does not provide an enrollment-history archive.

## Campus Admins and Main Admin

Use **Administration → Newsletters** to draft school updates, choose readers and explicit campus/class/stream targets, and add optional text/file attachments. Campus Admins manage their own campus. Main Admin can choose both campuses; this creates explicit targets for each side.

Choose release/expiry in school time (Africa/Harare), optionally pin the update, then publish. Draft, scheduled, expired and archived updates do not appear in the parent feed. A staff-only update is also hidden from parents. To change targets on a published update, return it to draft first. A school notice can be text-only; teacher notes require a finalized file before publication. No redeployment is needed when content changes.

Use **Library oversight** to trace teacher notes and newsletter availability. Admins do not upload or edit teachers' notes from this view. Verify campus, class, stream, publication state and current attachment. **Activity for …** shows recorded changes and the actor. Both-campus newsletter audit details are Main Admin-only.

## Accountants

Open **Workspace → Library oversight**. The campus is locked to your assigned campus. You can inspect teacher notes, their recorded activity and current attachments, and relevant published newsletters. You cannot create/edit/delete teacher notes, publish newsletters or change campus scope. Ask Main Admin to fix a missing/incorrect campus assignment.

When helping a parent, check the displayed content scope and release state, then the parent's verified learner connection and the learner's active enrollment in the existing learner workflow. Do not use another family's password/session. A support preview proves that support can read the file, not that every parent can.

## Parents and learners

1. Sign into the parent account and select the correct linked learner.
2. Open **Learning library** for teacher notes. Filter by subject, year or term. Grade/form and campus follow the selected learner's current enrollment.
3. Open the **Newsletters** bell/link for school updates. Switching learner changes the feed, including between Junior and Senior. The library, newsletter and dashboard links retain the selected learner.
4. Check file size before opening it. PDF/image files offer previews; Word/PowerPoint files download for a compatible app. Files do not download automatically.
5. If a private file link expires, request a new link. An already loaded preview can stay open. **Mark as read** acknowledges a newsletter for your parent account; it does not claim that the learner studied the document.

For missing notes, contact the office with the learner's campus/class, subject, title and approximate time. Do not send passwords, private links or screenshots containing other learners' information. If no verified learner appears, ask the school to verify the account connection. Historical reports remain in the existing record workflow.

## When the connection drops

Refresh the list and inspect saved state before retrying an upload or publication. A failed file replacement keeps the old active file. A signed link can still expire or be refused if access changed; refresh and request a new one. The portal does not queue offline writes or send newsletters by SMS/email. Do not create payments, fees, orders or learner records to test the library.
